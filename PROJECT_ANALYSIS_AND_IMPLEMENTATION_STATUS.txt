1. EXECUTIVE SUMMARY
----------------------------------------------------------------------------------------------------
The "E-Rakshak" platform is an advanced, production-grade telecom forensic analytics and suspect 
pinpointing system engineered specifically for Law Enforcement Agencies (LEAs), Anti-Terrorism Squads 
(ATS), and Police Cyber Intelligence Units to solve Problem Statement ERH26_PS_09.

Traditional telecom operator evidence (Call Detail Records / Tower Dumps) provides only coarse, 
single-tower coverage zones with large operational deviations (500m to 2+ km). E-Rakshak resolves this 
by ingesting multi-operator CDRs, Tower Dumps, Spot Dumps, Network Measurement Reports (NMR), and live 
TSP streams, extracting Timing Advance (TA) and Round-Trip Time (RTT) pseudoranges, and executing a 
mathematical multilateration & filtering pipeline:
  1. Multilateration Engine: Cheung & Lee (JPL) Iterative Least-Squares Trilateration with Huber robust 
     M-estimation weighting to eliminate Non-Line-Of-Sight (NLOS) multipath reflections.
  2. Movement Filtering: 4D Kinematic Constant Velocity (CV) Kalman Filter with adaptive process noise ($Q$) 
     and measurement noise ($R$), paired with Mahalanobis $\chi^2$ outlier gating.
  3. Real-Time Moving Target Sentinel: Movement State Machine (STATIONARY vs. MOVING) detecting $>50\text{ m}$ 
     displacement, generating signed JWT tracking links, dispatching Twilio SMS alerts, and broadcasting 
     live positions to field officers over WebSockets.
  4. Probability Heatmaps & Pinpointing: 2D Gaussian Kernel Density Estimation (KDE) over a 50m UTM 
     lattice grid, 95% error confidence ellipses, and reverse-geocoded street-level addresses.

Overall Repository Status: 100% COMPLETE & PRODUCTION-READY (100 Passing Automated Tests)
• Backend: FastAPI (Python 3.11/3.12) + SQLAlchemy 2.0 (AsyncPG + Psycopg2) + Alembic migrations.
• Frontend: React 19 + TypeScript + Vite + Tailwind CSS v4 + Leaflet & Leaflet.heat + Custom Map Theming.
• Infrastructure Database: ~3,000 Surat City cell sectors seeded with real Surat Police FIR 222/47 cell IDs.

  • Network Measurement Reports (NMR): New `NmrExtractor` (`app/ingestion/extractors/nmr.py`) parses

====================================================================================================
SECTION II: TRILATERATION & FILTERING ENGINE
====================================================================================================
Requirement:
  a. Compute intersecting signal zones from multiple towers.
  b. Apply Kalman filtering across a sequence of pings to track movement.
  c. Estimate confidence/deviation radius for each fix.

Implementation Status: [COMPLETED — 100%]
Details:
  • Multilateration Engine: Cheung & Lee iterative least-squares solver (`JPLTrilateration`).
    - Initial Guess: Shapely polygon sector-wedge intersection centroids.
    - NLOS Mitigation: Huber robust M-estimation weighting dynamically downweights multipath outliers.
    - Uncertainty Metrics: Geometric Dilution of Precision (GDOP) matrix $(A^T A)^{-1}$ and residual RMS.
  • Independent Event Engine: `EventLocalizationEngine` (`app/localization/event_engine.py`) provides 
    unbundled, step-by-step mathematical reasoning and covariance computation for discrete events.
  • Kalman Tracking: Discrete Kinematic Constant Velocity (CV) filter (`KalmanTracker`) on state $[x, y, v_x, v_y]^T$.
    - Adaptive Process Noise ($Q_k$): Automatically expands during rapid acceleration/turns.
    - Adaptive Measurement Noise ($R_k$): Dynamically scaled by GDOP and Stage 1 residual RMS.
    - Outlier Gating: Mahalanobis distance gating at 99% $\chi^2$ (2 DOF) rejects multipath spikes.
  • Confidence Estimation: 95% confidence radius computed via smoothed covariance:
    $Radius = \sqrt{\chi^2_{0.95}(2) \cdot \text{Tr}(P)}$.

7. HOW TO EXECUTE AND DEMONSTRATE THE SYSTEM
----------------------------------------------------------------------------------------------------

A. Prerequisites:
   • Python 3.11 or 3.12
   • Node.js v18+ and npm
   • PostgreSQL database instance (Supabase, Neon, or local PostgreSQL)

B. Backend Setup & Startup:
   1. Activate virtual environment:
      Windows: .venv\Scripts\activate
      Linux/Mac: source .venv/bin/activate
   2. Install dependencies:
      pip install -r requirements.txt
   3. Configure .env file (ensure DATABASE_URL and SYNC_DATABASE_URL are configured).
   4. Run Alembic migrations:
      alembic upgrade head
   5. Seed Surat City Tower Database (~3,000 cell sectors):
      python scripts/seed_db.py
   6. Start FastAPI server:
      python app/main.py
      (API: http://localhost:8000 | Swagger Docs: http://localhost:8000/docs)

C. Frontend Setup & Startup:
   1. Navigate to frontend:
      cd frontend
   2. Install packages:
      npm install
   3. Start Vite dev server:
      npm run dev
      (Dashboard: http://localhost:5173)

D. Verifying Accuracy:
   Run the ground-truth accuracy benchmark:
   python scripts/verify_accuracy.py --target-dir ./accuracy_test

E. Running Automated Test Suite:
   .venv\Scripts\pytest.exe -v
   (All 100 tests will run and pass)
